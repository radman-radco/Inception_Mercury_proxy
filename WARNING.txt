--------------------------------------------------------------------------------
WHAT THIS SOFTWARE DOES
--------------------------------------------------------------------------------

This proxy connects to chat.inceptionlabs.ai — Inception Labs' public web chat
endpoint for their Mercury model — and exposes it as a local OpenAI-compatible
HTTP API.

It does this by:

  - Impersonating a real Chrome browser's TLS fingerprint to pass Vercel's
    bot-detection layer (using the `impit` library).
  - Obtaining and rotating short-lived session tokens from /api/session.
  - Optionally routing requests through a pool of third-party HTTP proxies,
    each with its own IP address and independent rate-limit budget.

THIRD-PARTY PROXIES
--------------------------------------------------------------------------------

The included proxies.txt file contains IP addresses of third-party HTTP proxy
servers sourced from public lists. These servers are not operated by this
project and their operators have not consented to being listed here.

By using the proxy pool you are routing your traffic through infrastructure you
do not control. Consider:

  - The proxy operator can observe your unencrypted traffic.
  - Requests to Mercury appear to originate from the proxy's IP, not yours.
  - Free proxy lists are publicly scraped; there is no vetting for safety
    or legality of individual nodes.

Use the proxy pool at your own risk. Remove proxies.txt or set
"proxy.enabled": false in config.json to disable this feature entirely.
